# wheretopray

Find every place a Muslim can pray: mosques (masjid), dargahs, idgahs, musallas and prayer rooms. Starting with Bengaluru.

## Run

```bash
npm install
npm run dev          # http://localhost:3000
npm run import:osm   # refresh data/places.json from OpenStreetMap (Overpass)
npm run lint && npm run typecheck && npm run build
```

Copy `.env.example` to `.env.local` and set `ADMIN_TOKEN` (used by `/admin`).

## Pages
- `/` map (MapLibre + OSM tiles) with searchable list, type/area/facility filters, Near me
- `/place/[slug]` place details, Aladhan prayer times, directions, report a fix
- `/submit` add a place (goes to the moderation queue)
- `/admin` moderation queue (token protected)
- `/city/bengaluru` SEO city page, plus `/sitemap.xml`

## Data
- `data/places.json` is generated by `scripts/import-osm.ts` from OpenStreetMap (ODbL, "© OpenStreetMap contributors").
- Submissions are stored in `data/queue/submissions.json` (local only; not durable on serverless hosts).
- `src/lib/data.ts` defines a `PlaceRepository` interface. Swap the JSON implementation for Supabase using `supabase/migrations/0001_places.sql` (PostGIS, `places_near()` function).
- Never store Google Places content. Every record keeps `source`, `source_id` and `last_verified`.
